# Acklistings

Information exchange for Nantucket real estate brokers. A modern message board where island brokers share off-market listings, post buyer needs, and discuss market insights.

## Forum Categories

- **Off-market Listings** — Share and discover exclusive listings not on the open market
- **Off-market Needs** — Post buyer or tenant needs; connect with brokers who have matching inventory
- **Miscellaneous** — General discussion, referrals, market insights, and industry news

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS

## Getting Started

```bash
cd projects/acklistings
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).
